# Отчёт по лабораторной работе №1

**Тема:** Реализация конечного автомата для распознавания формальных языков

**Вариант:** 19

Выполнил(а): Иордатий Игнат Группа: IA2403ru

## 1. Цель работы

Разработать программу, реализующую детерминированный конечный автомат (ДКА), который распознаёт слова формального языка, заданного вариантом, и по любой входной последовательности символов даёт однозначный ответ: принадлежит слово языку или нет.

## 2. Постановка задачи

Необходимо разработать программное решение, реализующее ДКА для распознавания слов формального языка согласно индивидуальному варианту. Вариант задаёт общий вид допустимых слов регулярным выражением с параметрами (степенями повторения блоков) и ограничениями на эти параметры. Слово считается корректным, если его структура в точности соответствует шаблону и выполнены все условия на количество повторений блоков.

Программа должна принимать на вход произвольную последовательность символов, анализировать её автоматом и выдавать однозначное заключение о принадлежности слова языку. Дополнительно требуется провести верификацию решения на репрезентативной выборке корректных и некорректных входных данных.

## 3. Задание (вариант 19)

Язык: **aⁿ(bc)ᵐ(de)ᵏ**, где n ≥ 1, m ≥ 1, k ≥ 1, m — нечётное.

Алфавит: Σ = {a, b, c, d, e}.

Примеры допустимых слов: `abcde`, `aabcbcbcde`, `abcbcbcdede`.

Примеры недопустимых слов: `abcbcde` (m = 2, чётное), `bcde` (n = 0), `abcd` (k = 0).

## 4. Теоретические сведения

**Детерминированный конечный автомат** — это пятёрка M = (Q, Σ, δ, q₀, F), где:

- Q — конечное множество состояний;
- Σ — входной алфавит;
- δ: Q × Σ → Q — функция переходов (по состоянию и символу задаёт следующее состояние);
- q₀ ∈ Q — начальное состояние;
- F ⊆ Q — множество заключительных (принимающих) состояний.

Автомат читает слово по одному символу слева направо. В каждый момент он помнит только своё текущее состояние. Слово **принадлежит языку**, если после чтения последнего символа автомат находится в заключительном состоянии. Если для текущего состояния и символа перехода нет, автомат попадает в **ловушку** (состояние, из которого нельзя выйти), и слово отвергается.

Автомат не умеет считать символы, но может помнить конечную информацию, например чётность числа прочитанных блоков. Именно так в варианте 19 обеспечивается условие «m нечётное».

## 5. Построение автомата

### 5.1. Анализ языка

Условие «m нечётное, m ≥ 1» означает m = 1, 3, 5, … , то есть m = 1 + 2j, где j ≥ 0. Поэтому язык описывается регулярным выражением

**a⁺ · bc · (bcbc)* · (de)⁺*\*

Первый блок `bc` обязателен (m = 1), каждая следующая пара блоков `bcbc` сохраняет нечётность. Блоки `a` и `de` повторяются один или более раз.

### 5.2. Состояния автомата

| Состояние | Смысл |
| --- | --- |
| q0 | начальное, ничего не прочитано |
| q1 | прочитано aⁿ, n ≥ 1 |
| q2 | прочитана `b`, число блоков (bc) станет нечётным, ожидается `c` |
| q3 | прочитано (bc)ᵐ, m нечётное; допустимы `b` (новый блок) или `d` (переход к блокам de) |
| q4 | прочитана `b`, число блоков (bc) станет чётным, ожидается `c` |
| q5 | прочитано (bc)ᵐ, m чётное; допустима только `b` |
| q6 | прочитана `d`, ожидается `e` |
| q7 | прочитано (de)ᵏ, k ≥ 1; **заключительное**, допустима `d` |
| TRAP | ловушка (недопустимое слово) |

### 5.3. Формальное описание

- Q = {q0, q1, q2, q3, q4, q5, q6, q7, TRAP}
- Σ = {a, b, c, d, e}
- начальное состояние: q0
- F = {q7}

### 5.4. Таблица переходов

Прочерк обозначает переход в ловушку TRAP.

| Состояние | a | b | c | d | e |
| --- | --- | --- | --- | --- | --- |
| → q0 | q1 | — | — | — | — |
| q1 | q1 | q2 | — | — | — |
| q2 | — | — | q3 | — | — |
| q3 | — | q4 | — | q6 | — |
| q4 | — | — | q5 | — | — |
| q5 | — | q2 | — | — | — |
| q6 | — | — | — | — | q7 |
| \*q7 | — | — | — | q6 | — |
| TRAP | — | — | — | — | — |

Ключевой переход — q5 –b→ q2: блоки (bc) чередуют состояния «нечётно» (q3) и «чётно» (q5), а выход к блокам `de` есть только из q3.

### 5.5. Диаграмма состояний

&#91;image: Диаграмма состояний ДКА\]

Стрелки подписаны читаемым символом. Заключительное состояние q7 обведено двойным кругом. Все переходы, которых на схеме нет, ведут в ловушку TRAP (она не показана).

### 5.6. Примеры работы автомата

Слово `abcde` (n = 1, m = 1, k = 1):

q0 –a→ q1 –b→ q2 –c→ q3 –d→ q6 –e→ q7. Слово закончилось в q7 ∈ F, **принято**.

Слово `aabcbcbcdede` (n = 2, m = 3, k = 2):

q0 –a→ q1 –a→ q1 –b→ q2 –c→ q3 –b→ q4 –c→ q5 –b→ q2 –c→ q3 –d→ q6 –e→ q7 –d→ q6 –e→ q7. Слово закончилось в q7, **принято**.

Слово `abcbcde` (m = 2):

q0 –a→ q1 –b→ q2 –c→ q3 –b→ q4 –c→ q5, далее `d`: из q5 перехода по `d` нет, автомат попадает в TRAP. Слово **отвергнуто**.

## 6. Реализация

Программа написана на Python (файл `lab1_dfa.py`), эквивалентная версия на Java (файл `Lab1Dfa.java`). Таблица переходов хранится как словарь: `DELTA[состояние][символ]` даёт следующее состояние, отсутствие записи означает переход в ловушку.

```python
START = 'q0'
ACCEPTING = {'q7'}
TRAP = 'TRAP'

DELTA = {
    'q0': {'a': 'q1'},
    'q1': {'a': 'q1', 'b': 'q2'},
    'q2': {'c': 'q3'},
    'q3': {'b': 'q4', 'd': 'q6'},
    'q4': {'c': 'q5'},
    'q5': {'b': 'q2'},
    'q6': {'e': 'q7'},
    'q7': {'d': 'q6'},
}

def step(state, symbol):
    if state == TRAP:
        return TRAP
    return DELTA.get(state, {}).get(symbol, TRAP)

def run(word):
    state = START
    for ch in word:
        state = step(state, ch)
        if state == TRAP:
            break
    return state in ACCEPTING
```

Функция `run` читает слово по одному символу, на каждом шаге применяя функцию переходов. После окончания слова (или попадания в ловушку) проверяется, лежит ли автомат в заключительном состоянии. Программа также умеет выводить путь по состояниям и работает в интерактивном режиме.

Для проверки используется **независимый эталон**: регулярное выражение разбивает слово на три группы, программа вычисляет n, m, k и напрямую проверяет условия варианта (n, m, k ≥ 1 и m нечётное). Эталон не использует таблицу переходов, поэтому расхождение результатов указывало бы на ошибку в таблице.
