# Лабораторная 1. Конечный автомат (вариант 19)

Язык: a^n (bc)^m (de)^k, n ≥ 1, m ≥ 1, k ≥ 1, m нечётное.
Эквивалентное регулярное выражение: a+ bc (bcbc)* (de)+

Автомат: 8 состояний (q0–q7) и ловушка. Принимающее состояние: q7.

## Запуск

Python:

    python lab1_dfa.py                 # таблица переходов, тесты, интерактивный режим
    python lab1_dfa.py abcde abcbcde   # проверить конкретные слова

Java (11+):

    java Lab1Dfa.java
    java Lab1Dfa.java abcde abcbcde

## Состав

- lab1_dfa.py, Lab1Dfa.java: автомат, независимый эталон, тесты, интерактивный режим
- lab1_dfa.dot, lab1_dfa.png: диаграмма состояний (Graphviz)

## Тесты

Корректные и некорректные слова, граничные случаи, полный перебор всех слов
длины 0–9 над алфавитом {a,b,c,d,e} в сравнении с независимым эталоном
(расхождений нет).
