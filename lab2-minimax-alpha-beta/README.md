# Лабораторная 2. Минимакс и альфа-бета (вариант 19)

Глубина 6, ширина 3, значения листьев [0; 40].
Эксперимент: случайная перестановка потомков, 10 запусков, разброс числа узлов.

Допущения: корень MAX, уровни чередуются MAX/MIN; 729 листьев и 1093 узла.

## Запуск

    pip install -r matplotlib
    python lab2_minimax.py

Программа печатает таблицу и сводку, создаёт lab2_results.csv и lab2_chart.png.

## Результат

- Значение корня: 15 (одинаково у обоих алгоритмов во всех запусках)
- Оптимальный путь: [1, 0, 1, 2, 2, 1]
- Минимакс всегда посещает 1093 узла
- Альфа-бета: от 363 до 577 узлов, в среднем около 470 (экономия около 57 %)

Время выполнения зависит от компьютера.
